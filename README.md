# SIM7080 Module for M5Stack Unit

SIM7080モジュール（M5Stack Unit / Grove接続）通信を簡単に扱うためのIoTモジュールです。

---

## 概要

M5Stack社のM5Stamp CAT-M Module（SIM7080G）を搭載した通信ユニットです。  
Grove（HY2.0-4P）インターフェースにより、M5Stackシリーズと簡単に接続できます。

---

## 特徴

- SIM7080（LTE-M / NB-IoT）通信に対応
- M5Stackシリーズと高い親和性
- M5Stack社のM5Stamp CAT-M Module (SIM7080G)を搭載
- Grove（HY2.0-4P）接続
- 通信確認用LED(TX/RX)を搭載
- プラスチックケース付き

---

## 必要なもの

- M5Stack本体
- 本モジュール（sim7080-m5-unit）
- SIMカード（LTE-M / NB-IoT対応）

---

## 接続方法

Groveポートに接続して使用します。

---

## 想定用途

- センサーデータのクラウド送信
- SORACOMなどのIoT通信
- 遠隔モニタリング
